# 레이캐스트 FPS

브라우저에서 `index.html`을 더블클릭해서 여는 것만으로 실행되는
1인칭 슈팅 게임입니다. 서버·인터넷 연결·외부 라이브러리 없이
순수 HTML/CSS/JavaScript(Canvas 2D 레이캐스팅)로만 만들어졌습니다.

## 실행 방법

`fps-game/index.html` 파일을 아무 최신 브라우저(Chrome 권장)로
더블클릭해서 열면 바로 실행됩니다. 별도 설치나 빌드 과정이 없습니다.

## 조작법

| 입력 | 동작 |
|---|---|
| W / A / S / D | 이동 |
| 마우스 이동 | 시점 회전 |
| 좌클릭 | 발사 |
| 우클릭 | 정조준 (FOV 축소 + 탄퍼짐 감소 + 이속 감소) |
| R | 재장전 |
| 1 / 2 / 3 / 4, 마우스 휠 | 무기 교체 |
| Shift | 달리기 (탄퍼짐 증가) |
| ESC | 일시정지 / 포인터 락 해제 |

## 화면 흐름

메인 메뉴 → 로드아웃(스킨 + 무기 2개 + 맵 선택) → 게임
→ (ESC로 일시정지) → 게임오버(다시하기 / 로드아웃으로)

## 파일 구조

```
fps-game/
  index.html        진입점, 모든 화면의 DOM 구조
  css/style.css      전체 스타일 (메뉴, HUD, 반응형)
  js/config.js       무기 / 스킨 / 맵 / 밸런스 수치 테이블
  js/audio.js        Web Audio API 절차적 효과음
  js/textures.js     오프스크린 캔버스 절차적 벽 텍스처
  js/raycaster.js     DDA 레이캐스팅 렌더링 엔진 + 스프라이트 Z-버퍼
  js/player.js       이동/충돌/체력/입력 처리
  js/weapons.js      무기 로직, 히트스캔, 뷰모델 렌더링
  js/enemy.js        적 상태머신(IDLE→CHASE→ATTACK→DEAD) + AI + 스프라이트
  js/ui.js           메뉴, HUD, 미니맵, 킬피드
  js/main.js         게임 루프, 전체 상태 관리, localStorage 저장
```

전역 네임스페이스는 `window.GAME` 하나만 사용하며, 각 파일은 일반
`<script>` 태그로 순서대로 로드됩니다(ES 모듈 미사용 — `file://`에서도
CORS 에러 없이 동작).

## 밸런스 조정 방법

`js/config.js` 파일 하나만 수정하면 됩니다.

- `GAME.CONFIG`: 이동 속도, 반동, 웨이브 증가율, 드롭 확률 등 전역 수치
- `GAME.WEAPONS`: 무기별 데미지 / 연사속도 / 탄창 / 재장전 시간 / 탄퍼짐 / 사거리
- `GAME.SKINS`: 스킨별 체력 / 이동속도 / 재장전속도 / 색상 / 시야감지 감소
- `GAME.ENEMY_TYPES`: 적 종류별 체력 / 속도 / 데미지 / 사거리 / 점수
- `GAME.MAPS`: 맵 타일 배열 (0=바닥, 1~4=벽 종류)과 스폰 위치

다른 파일들은 이 테이블을 참조만 하므로, 수치 조정은 config.js 편집만으로 충분합니다.

## 기술 노트

- **렌더링**: Wolfenstein 3D 방식 DDA 레이캐스팅. 세로 스트라이프 단위로
  벽을 그리고, 거리 기반 명암 처리와 Z-버퍼 기반 스프라이트 가림 처리를 구현.
- **텍스처**: 벽돌 / 금속 / 돌 / 콘크리트 패턴을 오프스크린 캔버스에
  코드로 그려서 사용 (이미지 파일 없음).
- **사운드**: 오실레이터 + 화이트 노이즈로 발사/재장전/피격/처치음을
  실시간 합성 (오디오 파일 없음).
- **적 AI**: 레이캐스트로 벽 가림을 검사하는 시야 판정, 3종류(러셔/슈터/탱커)가
  서로 다른 속도·사거리·전투 방식으로 동작.
- **웨이브/저장**: 웨이브마다 적 수·체력 증가, 처치 시 드롭 확률, 설정과
  최고 점수는 `localStorage`에 저장되어 새로고침 후에도 유지됨.
- **성능**: delta-time 기반 이동, `requestAnimationFrame` 루프, 렌더
  해상도(1.0/0.75/0.5) 설정 가능.
